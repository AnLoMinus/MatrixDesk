# Contributing to MatrixDesk

Thanks for your interest in contributing!

## Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the renderer dev server:
   ```bash
   npm run dev
   ```
3. Launch Electron (in a separate terminal):
   ```bash
   npm run electron:dev
   ```

## Pull Requests

- Keep PRs focused and include a clear summary.
- Update docs when you change behavior.
- Ensure `npm run build` passes before requesting review.
